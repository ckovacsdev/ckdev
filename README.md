# ckovacs.dev

Personal site and portfolio. Built with React, TypeScript, and Vite.

**Live:** https://ckovacs.dev

## Design

| Desktop | Mobile |
|---|---|
| <img src="public/home-screenshot.png" width="600"> | <img src="public/home-screenshot-mobile.png" width="170"> |

## Design Ideals

- Art-deco visual system
- Responsive from 375px up, with fluid type and spacing via `clamp()`
- Respects `prefers-reduced-motion` throughout

## Stack

- React + TypeScript
- Vite
- HTML & CSS
- Deployed on CloudFlare

## Running locally

```bash
npm install
npm run dev
```
